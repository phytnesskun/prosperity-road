# 繁荣之路 · Prosperity Road

以 Pearson Edexcel International A Level Economics 为课程背景的课堂策略游戏。

当前《面包危机》可完成六个季度：观察正常市场、应对歉收、选择限价/补贴/公共投放、检查供需与账目、回放单季政策、完成学习报告。所有数值是透明的教学模型假设，不是现实预测。

## 怎么玩

1. 点击底部“查看正常市场”，建立第一季基准。
2. 在决策台点选“让市场调节 / 压低面包标价 / 鼓励私人生产 / 打开公共粮仓”，也可调整三项政策的组合。
3. 第2、4季点选两项预测方向和一个理由；也可自行输入理由。预测错误不会阻止继续。
4. 执行后立即查看居民实际购粮、价格、现金和储备，以及相同天气和期初资源下的无干预对照。
5. 点击“免费试算”比较其他组合；更改档位即时更新结果，不改写原记录。然后进入下一季。

底部主操作栏始终可见，手机上可直接跳到预测或政策区。目标进度持续显示；城镇、供需图和细账保留在探索标签中。原有浏览器存档仍可继续使用。

## 顾问与动态场景

- 点击底部「问林岚」或开场人物立绘，与原创经济顾问林岚进行选项式多轮对话：讨论当前政策、追问结果原因、考虑储备取舍，以及回答直觉挑战题。
- 点击动态场景中的农田、加工坊、市场、居民或公共粮仓，会打开对应话题。台词读取当季条件、政策和已结算数据；决策前只讲机制，不提前揭示精确结果。
- 结算会播放短时指标与面包流转动画。公共投放只有在真实执行后才出现运输；点击「重播流转」可重看，不会再结算或消耗资源。动画数量不代表成交数量，真实数量以标签为准。
- 顶部「动画：开/关」保存本浏览器的显示偏好，同时遵循系统“减少动态效果”设置。关闭动画后，数值、对话和全部操作仍可使用。
- 顾问采用本地情境对话，无需语言模型 API；目前按选项追问，不支持自由文本或语音。对话临时保留最近8条消息，换政策、换季或重置后按新局势更新，不写入学习报告。回放页面明确区分正式任期对话与替代方案。

人物素材与完整生成提示词见 [制作记录](docs/assets/advisor-lin-lan.md)。

## 学生试玩

[公开游戏链接](https://prosperity-road-ial.bingkunq.chatgpt.site/)无需学生登录。首轮建议3–5人、每人15–20分钟；[教师试玩包](docs/student-pilot.md)包含可转发通知、活动安排、观察表与学习检验题。

- 点击顶部「试玩与反馈」或开场入口，查看三步任务与中文操作演示。视频按需播放，也可下载到教室电脑。
- 学生可随时填写匿名代号、操作与兴趣评分、卡点、经济发现和改进建议；即使没有完成六季，也能下载包含实际游戏记录的Markdown反馈文件。
- 反馈草稿只保存在当前浏览器。网站不会自动向教师上传；学生需自行交回下载文件。游戏没有新增账号、埋点或数据收集后端。
- 共享设备换人前，先下载需要的报告与反馈，再点击「新任期」。确认后同时清空游戏和反馈；既有游戏存档格式保持兼容。

视频与可编辑制作脚本见 `docs/demo/`、`scripts/record-demo.mjs`。

## 本地运行

环境：Node.js 24.12 或更高版本、npm、现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。游戏在浏览器内运行，不需要后端数据库或 API 密钥。进度保存在当前浏览器的 localStorage；不同设备、浏览器和网址之间不会自动同步。报告可下载为 Markdown。

## 检查与构建

```bash
npm test
npm run build
```

- `npm test`：经济模型、季度状态、存档恢复、新剧本数值。
- `npm run check`：TypeScript 类型检查。
- `npm run build`：类型检查后生成 `dist/`。
- `npm run preview`：预览生产构建。

浏览器检查需要先在另一个终端运行 `npm run dev -- --port 5173 --strictPort`，然后执行：

```bash
npm run test:browser
node scripts/pilot-smoke.mjs
```

macOS 优先使用已安装的 Google Chrome。其他环境可先运行 `npx playwright install chromium`，或通过 `BROWSER_EXECUTABLE` 指定浏览器可执行文件。检查使用独立临时浏览器上下文，不读取个人浏览器资料。截图及测试下载保存在被 Git 忽略的 `.qa/`。

## 游戏与教学约定

- 第1季固定无干预；第2–6季每季重新选择政策。
- 第2、4季先记录两项方向预测及一个理由，可点选机制或自己写；不进行自动内容评分。真正更换政策才清空预测，再次点击同一组合会保留答案。
- 资源不足时整组政策不执行，既有资源与历史保持不变。
- 决策前展示可执行性与库存承诺，执行后才揭示精确市场结果与现金账目。
- 超额需求和基本篮子缺口分别记录；低价或市场出清不自动代表保障改善。
- 单季回放复制该季期初资源与外生条件，不改变原局、不延续到以后季度。
- 结算卡中的“政策影响”比较同季、同资源的无干预方案；预测对照上季，二者明确区分。补贴的单独效果另与保留其他政策、仅取消补贴的方案比较。
- 所有视图读取同一结算记录；计算保持完整精度，指标显示两位小数，说明文字使用一位小数。角色反馈来自模型数值。
- 教师可按 AO1–AO4 评价复盘，经营目标与学习评价分开；不自动生成 Pearson 考试等级。

## 发布与下一步

部署配置为 `.openai/hosting.json`，静态产物位于 `dist/`。按照教师授权，Sites 已开放公开访问，学生无需登录；GitHub `origin` 保持为本仓库。发布时使用已验证并推送的同一源代码状态。

下一步建议进行3–5名学生的小范围试教，观察独立完成情况、因果解释和陌生情境迁移，再调整引导与难度。《烟囱与河流》可在规则审阅后接入相同的界面流程。
