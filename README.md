# 繁荣之路 · Prosperity Road

以 Pearson Edexcel International A Level Economics 为经济规则依据的城镇策略游戏。

当前《面包危机》可完成六个季度：观察正常市场、应对歉收、选择限价/补贴/公共投放、听取街头反应、尝试替代政策，最后查看自动生成的任期战报。经济概念决定世界如何响应玩家；所有数值是透明的模型假设，不是现实预测。

## 怎么玩

1. 点击底部“查看正常市场”，建立第一季基准。
2. 先看局势，再点选“让市场调节 / 压低面包标价 / 鼓励私人生产 / 打开公共粮仓”；需要组合政策时展开“微调政策组合”。
3. 选好方案后直接点击“执行本季政策”。没有预测题、答案检查或理由填写要求。
4. 执行后先看城镇变化与居民反应，再看实际购粮与价格变化；想研究细节时，再打开账目、供需图或同季政策对照。
5. 点击“免费试算”比较其他组合；更改档位即时更新结果，不改写原记录。然后进入下一季。

主循环是“看局势 → 做决定 → 看世界回应 → 再尝试”。顶部保留国库、储备与达标进度，季度放在主面板标题中，底部操作栏始终可见。城镇按需走访，图表与细账收在“账本”，规则、动画和反馈收在“菜单”。六季结束后自动生成战报，可以下载“面包危机-任期记录.md”。原有浏览器存档仍可继续使用。

## 顾问与动态场景

- 点击底部「问林岚」或开场人物立绘，与原创经济顾问林岚进行选项式多轮对话：讨论当前政策、追问居民处境、考虑储备取舍。她直接回应问题，不向玩家出题。
- 点击农田、加工坊、市场、居民区，分别走访农民陈禾、工人阿诚、售货员阿芸和居民周婶。人物先说一句近况，点击原料袋、成品筐、账本等物件再展开数据；可顺着生产链走到下一处，或回政策桌尝试办法。公共粮仓仍由林岚说明。
- 台词与物件读取当季条件、草案或真实结算；尚未执行时不展示预测成交结果。结算后两位街坊会直接回应，可点击反应继续走访。所有走访均可关闭或跳过，不改变存档和资源。
- 结算会播放短时指标与面包流转动画。公共投放只有在真实执行后才出现运输；点击「重播流转」可重看，不会再结算或消耗资源。动画数量不代表成交数量，真实数量以标签为准。
- 「菜单」中的「动画：开/关」保存本浏览器的显示偏好，同时遵循系统“减少动态效果”设置。关闭动画后，数值、对话和全部操作仍可使用。
- 顶部「♫ 配乐」可开关当前音乐，默认使用原创城镇配乐。首次游戏操作后才低音量播放，静音偏好保存在本浏览器；切到后台或打开试玩演示面板时暂停，返回游戏后恢复。音频加载失败不会阻止游玩。
- 「菜单」→「音乐库」列出16首参考曲目，未导入时显示「待选择」。可批量选择本地音频按文件名匹配，也可逐曲选择文件；未匹配文件列为其他本地曲目。已导入曲目可切换、循环播放，也可恢复原创配乐。本地文件只通过当前页面的 Blob URL 播放，不上传、不加入公开网站或演示视频；刷新后需要重新选择文件。
- 《面包危机》的林岚与四位街坊有独立角色配音。「菜单」中可单独选择中文、English 或关闭，偏好保存在本浏览器，不跟随系统或界面语言。走访、查看物件和追问时播放对应的简短回应，配音字幕显示实际口播内容，详细数值仍由原有对话与账本提供。
- 对话可重播或停止；换人物、关闭对话或切到后台会停止当前配音。说话时背景配乐自动降低，结束后恢复。配音为制作时生成的标准合成声，游戏只播放静态音频，无需麦克风、语音服务或 API 密钥；加载失败仍可阅读文字和继续游玩。
- 顾问采用本地情境对话，无需语言模型 API；目前按选项追问，不支持自由文本或麦克风语音聊天。对话临时保留最近8条消息，换政策、换季或重置后按新局势更新。回放页面明确区分正式任期对话与替代方案。

人物素材与完整生成提示词见 [林岚制作记录](docs/assets/advisor-lin-lan.md)及[四位街坊制作记录](docs/assets/townspeople.md)。
原创配乐与复现方式见 [配乐制作记录](docs/assets/town-theme.md)。

## 学生试玩

[公开游戏链接](https://prosperity-road-ial.bingkunq.chatgpt.site/)无需学生登录。首轮建议3–5人、每人15–20分钟；[教师试玩包](docs/student-pilot.md)包含可转发通知、试玩安排与观察表，重点看玩家能否自主操作、理解后果并愿意再试一次。

- 「菜单」→「试玩与反馈」提供可选提示、中文演示与反馈入口。无需打开该入口、看完视频或提交反馈才能继续游戏。
- 学生可自愿填写匿名代号、操作与兴趣评分、卡点、发现和改进建议；即使没有完成六季，也能下载包含实际游戏记录的 Markdown 反馈文件。
- 反馈草稿只保存在当前浏览器。网站不会自动向教师上传；学生需自行交回下载文件。游戏没有新增账号、埋点或数据收集后端。
- 共享设备换人前，先下载需要的任期记录与反馈，再从「菜单」点击「新任期」。确认后同时清空游戏和反馈；既有游戏存档格式保持兼容。

视频与可编辑制作脚本见 `docs/demo/`、`scripts/record-demo.mjs`。

## 本地运行

环境：Node.js 24.12 或更高版本、npm、现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。游戏在浏览器内运行，不需要后端数据库或 API 密钥。进度保存在当前浏览器的 localStorage；不同设备、浏览器和网址之间不会自动同步。任期记录可下载为 Markdown。

## 检查与构建

```bash
npm test
npm run build
```

- `npm test`：经济模型、季度状态、存档恢复、新剧本数值。
- `npm run check`：TypeScript 类型检查。
- `npm run build`：类型检查后生成 `dist/`。
- `npm run preview`：预览生产构建。

浏览器检查需要先在另一个终端运行 `npm run dev -- --port 5173 --strictPort`，然后执行：

```bash
npm run test:browser
node scripts/townspeople-smoke.mjs
node scripts/pilot-smoke.mjs
node scripts/audio-smoke.mjs
node scripts/music-library-smoke.mjs
```

macOS 优先使用已安装的 Google Chrome。其他环境可先运行 `npx playwright install chromium`，或通过 `BROWSER_EXECUTABLE` 指定浏览器可执行文件。检查使用独立临时浏览器上下文，不读取个人浏览器资料。截图及测试下载保存在被 Git 忽略的 `.qa/`。

## 第二剧本：烟囱与河流

[直接试玩四季样品](https://prosperity-road-ial.bingkunq.chatgpt.site/?scenario=river)，也可从《面包危机》的「菜单」进入。两个剧本使用独立存档，切换或重开第二剧本不会删除第一剧本的进度。

第一季开动纸厂，随后应对河岸请愿、枯水与新订单。玩家在自由生产、单位污染税与排放上限之间选择，执行后立即看到本季供货、价格、排放、损害和财政反馈。点击纸厂、河岸、码头听取不同角色的反应；林岚解释同季对照，不提出答题要求。

四季目标为累计交付至少130、损害不超过3000、国库非负。第二至四季结算后可免费试算该季其他方案，使用原有环境与期初现金，不修改正式任期。四季结束自动生成结局与任期账本，可以重新尝试。河水颜色只表示本季损害，不模拟长期污染存量或健康人数。

样品入口由 `src/entry.ts` 按查询参数选择；规则在 `src/river-model.ts`，交互在 `src/river.ts`，场景在 `src/river-scene.ts`。三张策略卡、场景对话和可展开账本是当前范围，原设计稿中的供需图与教师评价材料没有放入必经流程。

浏览器验收：`node scripts/river-smoke.mjs`（先启动本地预览）。模型验收同时核对剧本数值、216条政策路径、预算、重复执行及存档篡改。

## 世界规则与边界

- 第1季固定无干预；第2–6季每季重新选择政策。
- 所有决策季选好政策就能执行；对话、细账、试算与反馈均可选，不设置答题或作文关卡。
- 资源不足时整组政策不执行，既有资源与历史保持不变。
- 决策前展示可执行性与库存承诺，执行后才揭示精确市场结果与现金账目。
- 超额需求和基本篮子缺口分别记录；低价或市场出清不自动代表保障改善。
- 单季回放复制该季期初资源与外生条件，不改变原局、不延续到以后季度。
- 结算卡中的“政策影响”比较同季、同资源的无干预方案。补贴的单独效果另与保留其他政策、仅取消补贴的方案比较。
- 所有视图读取同一结算记录；计算保持完整精度，指标显示两位小数，说明文字使用一位小数。角色反馈来自模型数值。
- 战报自动整理经营结果与关键事件，不要求填写学习报告，也不生成 Pearson 考试等级。

## 发布与下一步

部署配置为 `.openai/hosting.json`，静态产物位于 `dist/`。按照教师授权，Sites 已开放公开访问，学生无需登录；GitHub `origin` 保持为本仓库。发布时使用已验证并推送的同一源代码状态。

下一步建议进行3–5名学生的小范围试玩，观察操作卡点、对世界反馈的理解、主动探索与再玩意愿，再调整引导与难度。《烟囱与河流》目前为四季样品，可重点比较两条通关路径和不同角色的反应。
