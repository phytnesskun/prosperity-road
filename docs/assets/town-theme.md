# 小镇清晨配乐

- 文件：`public/audio/town-theme.mp3`；生成脚本：`scripts/compose-music.py`。
- 制作日期：2026-10-21。
- 用途：游戏界面的安静循环配乐，也供演示视频在旁白下方铺底。
- 来源：为本项目编写的原创旋律、和声编排与合成音色。未使用第三方歌曲、录音、音源采样或网络下载的音乐。
- 风格：温暖的轻三拍小镇主题，以柔和的毡音钢琴感旋律、弱拨弦分解和弦和轻弦乐底色组成；无歌词、无鼓点。
- 乐曲：F 大调，76 BPM，3/4 拍，32 小节；包含主题、回应、桥段和回归。音符力度与起音有固定种子的轻微变化。
- 导出：75.78948 秒音频内容，44.1 kHz 双声道 MP3，80 kb/s，758,695 字节（约 741 KiB）。MP3 带编码延迟/填充信息，支持无缝解码的播放器会使用实际样本长度。
- 电平：编码前峰值 −8.0 dBFS；编码后测得综合响度 −18.5 LUFS、真峰值 −8.4 dBFS、响度范围 1.7 LU。界面以 0.24 音量播放；视频仍需单独压低并在旁白出现时让位。
- 循环：所有跨边界音符与房间反射尾音环绕到开头，首尾没有整段静音或收尾重击。不要给游戏源文件加入整体淡出；首次启动和暂停可由播放器淡入淡出。视频成片可以独立淡入淡出。

## 重新生成

需要 Python 3、NumPy 与 ffmpeg，仅用于制作资产，不增加网页运行时依赖。

```sh
python3 scripts/compose-music.py
```

脚本依次使用 `FFMPEG` 环境变量、系统 `ffmpeg`，或现有的 `.qa/demo/tools/imageio_ffmpeg` 中的二进制。也可用 `--output /absolute/path/theme.mp3` 导出到其他位置。固定随机种子为 `20261021`；中间 WAV 和参数记录保存在忽略的 `.qa/audio/` 下。

## 技术检查

- ffmpeg 完整解码成功，解码后 3,342,316 个双声道样本帧，无削波样本。
- 解码后的首尾相邻样本差为 0.00385（归一化幅度），低于循环边界附近普通样本最大变化 0.00998；没有额外突变尖峰。
- 电平测量使用 ffmpeg `ebur128=peak=true`，日志保存在 `.qa/audio/loudness.txt`。
- 这些检查确认编码、电平与边界连续性；“自然”“耐听”仍是听感判断，最终以实际游戏和视频试听为准。
