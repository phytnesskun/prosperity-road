# Edexcel IAL 面包危机剧本与经济规则

《面包危机》是《繁荣之路》的首个课堂剧本，以 Edexcel International A Level Economics 的 Unit 1 为教学基准。学生担任小国的经济部长，在歉收后选择限价、生产补贴和公共储备投放，观察居民购粮、生产者收益和政府资源的变化。

本版明确六回合流程、初始参数、政策边界、结算公式、图表、学习评价和原型验收条件。数值为专门设计的教学假设，供开发和课堂讨论使用，不是现实经济预测。版本日期：2026年10月20日。

# 学习目标与课程对应

完成本关后，学生应能解释歉收如何改变均衡，区分价格下降与实际购粮改善，比较受产能约束的补贴与库存投放，并使用本局证据作出有条件的政策判断。

| 考纲位置 | 本关涉及的内容 | 学生留下的证据 |
|---|---|---|
| 1.3.1 | 稀缺、机会成本、模型假设 | 解释为何本季释放储备会减少未来选择 |
| 1.3.2 | 需求、沿曲线移动、PED | 使用两个未配给的均衡点计算并解释需求弹性 |
| 1.3.3 | 供给移动、PES与时间和产能 | 区分成本变化与原料数量上限 |
| 1.3.4 | 均衡、价格机制、补贴及受益分配 | 比较价格、成交量和不同群体所得 |
| 1.3.5 | 市场失灵与物品性质的辨析 | 解释歉收涨价为何不能自动等同市场失灵 |
| 1.3.6 | 限价、补贴、国家供给与政府失灵 | 评价干预的作用条件、资源成本与意外结果 |

这里只覆盖上述条目的相关部分，不代表完成整个 Unit 1。面包即使由政府出售，仍具有竞争性和排他性；政策发生支出，也不能单独据此判定政府失灵。[课程依据](https://qualifications.pearson.com/content/dam/pdf/International%20Advanced%20Level/Economics/2018/Specification-and-Sample-Assessment/International-A-Level-Economics-spec.pdf)

# 玩家目标与课堂安排

玩家管理政策，私营食品行业按市场条件供给。地图分为农业区、加工区和居民区，公共粮仓是现有设施。地图显示同一市场中的原料、面包和消费变化；地区之间暂不单独定价。

开局公开三项目标：六季中至少五季使低收入组的基本篮子完成率达到95%；结束时保留不少于20单位公共储备；所有已执行政策的国库余额均不得为负。指标阈值是本剧本的游戏目标，不代表社会福利的完整定义。

用约3分钟完成基期引导，五次政策回合合计约15分钟，再用5–10分钟回放和复盘。界面拟使用英文经济术语，中文解释可展开；该语言设置是原型默认，可在试教后调整。

居民、生产者和财政官员提出不同诉求，发言必须引用真实模拟结果。短缺、利润下降等反馈按计算结果触发，不根据玩家点了哪个政策按钮预设结局。

# 六回合剧本

| 回合 | 当季情境与外生条件 | 决策与教学重点 |
|---|---|---|
| 1 正常市场 | 原料上限110，额外成本0；价格5，成交100 | 引导回合固定无干预；查看粮仓、预算与两组居民购粮，理解机会成本 |
| 2 歉收抵达 | 原料上限70，额外成本2 | 所有政策开放；先预测价格与低收入组购粮方向，再提交组合 |
| 3 原料仍紧张 | 原料上限80，额外成本1.5 | 检查上季结果；区分供给数量、购买意愿和实际配给 |
| 4 恢复初期 | 原料上限100，额外成本1 | 重新判断补贴能否增加产量；在看结果前完成第二次预测 |
| 5 恢复后期 | 原料上限110，额外成本0.5 | 比较继续干预与退出，考虑财政、居民和生产者 |
| 6 恢复正常 | 原料上限110，额外成本0 | 提交最后一季政策；查看目标、回放一个决策并完成复盘 |

每季结算后，政策到期。下一季默认无干预，并清楚显示上季措施已到期，玩家可一键重新选择上季组合。

天气恢复路径由剧本预设，所有政策路径共用。补贴不会自动改变下一季原料上限；本版尚未引入投资、预期和私人库存。学生可以在规则页看到这一假设，避免把天气恢复误认为政策成果。

# 初始状态与计量约定

所有数量以抽象的“面包篮单位”计，价格、预算与成本使用游戏货币 credits。数量不是人数；完成率不能写成“多少家庭已经吃饱”。一个粮食等价单位可转化为一个面包篮单位。

| 参数 | 初始值或含义 |
|---|---|
| 国库 B | 160 credits |
| 公共粮食储备 R | 60单位，与私营当季原料来源分开 |
| 储备账面单位成本 | 3 credits，用于记录公共资产减少 |
| 公共转换配送费用 | 每投放1单位支出0.5 credits |
| 私营行业固定成本 | 每季合计30 credits |
| 私营原料上限 K | 六季依次为110、70、80、100、110、110 |
| 额外单位成本 c | 六季依次为0、2、1.5、1、0.5、0 |
| 总加工能力 | 每季130单位，覆盖允许的私营产量与公共投放组合 |
| 居民组 | 低收入组 L 和高收入组 H，统计时等权 |
| 每组基本篮子目标 | 36单位，属于课堂保障目标 |

两组各用一个代表性消费者描述，收入差异体现在需求参数中；收入和工资暂不另行循环计算，也不显示未经建模的家庭现金余额。两条曲线并不是关于所有低收入、高收入家庭行为的普遍断言。

K 是当季私营生产可使用的原料数量上限，不是已经生产出来的面包。未使用的能力不会记入公共粮仓。公共储备则是能够跨季保存的实物存量。

# 政策操作规则

| 工具 | 可选数值 | 生效和约束 |
|---|---|---|
| 最高价格 | 不设上限，或4、5、6 | 与同一补贴和投放组合下的无约束均衡价比较；低于该均衡价才构成有效约束 |
| 单位生产补贴 s | 0、1、2 | 只支付给私营当季实际产量；不能增加当季原料上限K |
| 公共投放 r | 0、10、20 | 从已有储备提取，转换成面包后按当季市场价格销售；不得超过现有储备 |
| 撤销政策 | 将对应工具设为无或0 | 以后续结算为准，不回溯修改历史 |

公共投放属于售粮，不是免费发放或向家庭转移支付。销售所得进入国库，转换配送费用另付。第一版不提供重新采购储备，期末保留目标使学生必须考虑跨季取舍。

提交前先用选定组合试算结算。库存不足或预计期末现金为负时，整个组合不执行，并说明需要减少哪项承诺；不会偷偷降低补贴、截断库存或让余额变负。允许当季售粮所得参与同季结算，这是明确的课堂结算约定。

提交前展示预算与库存约束；精确市场结果在提交后揭示，以保留学生预测和判断的空间。

# 市场结算规则

每回合按固定顺序运行：读取当季外生条件和期初资源；接受政策组合；求无约束均衡；判断限价；按实际价格计算产量与配给；核对资源；一次性提交状态和记录。输入无效时保留期初状态。

用 p 表示消费者实际支付的单价。两组购买意愿与总需求为：

```text
dL(p) = max(80 − 8p, 0)
dH(p) = max(100 − 8p, 0)
D(p)  = dL(p) + dH(p)
```

私营供给和包含公共投放的总供给为：

```text
qPrivate(p) = min(K, 20 × max(p + s − c, 0))
qTotal(p)   = qPrivate(p) + r
```

先解 D(p*) = qTotal(p*)。在本版参数范围中可在0至12.5之间用二分求根。没有限价时 p = p*；有上限 Pmax 时 p = min(p*, Pmax)。计算应保留完整精度，只在界面四舍五入到两位小数。

限价约束时，按两组在该价格下的需求比例分配现有面包：

```text
a = min(1, qTotal / D)
xL = a × dL
xH = a × dH
市场超额需求 = max(D − qTotal, 0)
低收入组基本篮子完成率 = min(xL / 36, 1)
高收入组基本篮子完成率 = min(xH / 36, 1)
综合完成率 = 两组完成率的平均值
基本篮子缺口 = max(36 − xL, 0) + max(36 − xH, 0)
```

比例配给是剧本设定的分配制度，界面必须公开说明。组内由代表性消费者优先满足边际愿付最高的消费单位；不模拟排队耗时、黑市和个体家庭差异。

市场超额需求与基本篮子缺口必须分列。自由价格可以使市场出清，同时低收入组依旧未达到保障目标；因此不能用“超额需求为零”宣称居民生活问题已经解决。

# 生产者与公共账目

私营部门在本版中合并为一个行业，边际成本和可变成本保持一致：

```text
MC(q) = c + q/20
VC(q) = c×q + q²/40
私人销售收入 = p×q
私人补贴收入 = s×q
生产者剩余 = (p+s)×q − VC(q)
私人行业利润 = 生产者剩余 − 30
```

q 始终只指私营实际产销量，不含公共投放。原料上限绑定时会出现稀缺收益；本版不细分其在农民、加工厂和土地所有者之间的分配。固定成本短期已承担，首版不加入企业进入或退出。

政府结算为：

```text
售粮收入 = p×r
转换配送支出 = 0.5×r
补贴支出 = s×q
下一季现金 = B + p×r − 0.5×r − s×q
下一季储备 = R − r
公共账面资产 = 现金 + 3×储备
```

历史账面成本3r只用于记录资产减少，不能重复从当期现金扣除。售粮会把储备转换成现金，不能把现金增加直接称为“社会净收益”；历史账面成本也不等于当前机会成本。

可展开的剩余图按代表性消费者假设计算：

```text
低收入组消费者剩余 = 10xL − xL²/16 − p×xL
高收入组消费者剩余 = 12.5xH − xH²/16 − p×xH
```

基期两组消费者剩余分别为100和225，生产者剩余250，行业利润220。限价下的消费者剩余依赖上述配给假设；不用这些局部指标直接合成国家福利分数。

# 界面与图表要求

主画面保留三地区地图。农业区显示原料约束，加工区显示实际私人产量，居民区显示两组实际购粮，粮仓显示剩余储备。动画和新闻均读取本轮结算记录。

顶部只显示当前价格、低收入组保障率、公共储备和现金；政策面板位于右侧。底部显示本轮事件与结果，点击指标可展开解释。

| 视图 | 必须呈现的内容 |
|---|---|
| 供需图 | 横轴数量、纵轴单价；需求、私人供给、含公共投放的总供给；无约束均衡、实际价格与超额需求 |
| 居民比较 | 两组购买意愿、实际购粮及36单位目标线 |
| 资源账目 | 期初与期末现金、储备，售粮收入、配送费用、补贴支出 |
| 历史回放 | 同一初始状态及外生路径下，两种政策的结果差异 |

原料上限形成供给曲线的垂直段；补贴改变消费者价格对应的私人供给，公共投放则加到市场可售量上。供需图从模型函数绘制，价格历史从回合记录绘制，不能从价格历史反推一条假供需曲线。

首版不显示通胀率、GDP、失业率或居民满意度的任意加减分。单一面包价格变动不能当作全经济通胀。

# 数值示例与政策比较

以下每行是独立的单季试算，期初现金均为160、储备均为60；行与行之间不接续。价格为显示值，结算使用未四舍五入数值。

| 单季独立比较 | 价格 | 总成交量 | 低收入组购粮 | 超额需求 | 期末现金 |
|---|---:|---:|---:|---:|---:|
| 基期 无政策 | 5.00 | 100.00 | 40.00 | 0.00 | 160.00 |
| 歉收 无政策 | 6.88 | 70.00 | 25.00 | 0.00 | 160.00 |
| 歉收 限价5 | 5.00 | 60.00 | 24.00 | 40.00 | 160.00 |
| 歉收 补贴1 | 6.88 | 70.00 | 25.00 | 0.00 | 90.00 |
| 歉收 储备20 | 5.63 | 90.00 | 35.00 | 0.00 | 262.50 |
| 歉收 限价5及储备20 | 5.00 | 80.00 | 32.00 | 20.00 | 250.00 |
| 恢复初期 无政策 | 5.56 | 91.11 | 35.56 | 0.00 | 160.00 |
| 恢复初期 补贴1 | 5.00 | 100.00 | 40.00 | 0.00 | 60.00 |

歉收时无干预的实际价格为6.875。限价5将低收入组购粮从25降到24；模型中的低标价并未改善该组获得的数量。每单位补贴1则使国库支出70，但原料上限使产量仍为70。到恢复初期，同样补贴能把私人产量从91.11提高到100。

在基期释放20单位储备时，私人产量从100降到88.89，总成交量只增加到108.89。库存进入市场后会改变价格和私人生产，不能直接给原有均衡销量加20。

六季路径比较使用同一初始状态，第一季均无干预。“限价5”指第2至第5季限价；“分两期释放储备”指第2、3季各投放20；“储备衔接恢复期补贴”在这两次投放之外，于第4季增加单位补贴1。

| 六季政策路径 | 达到低收入组95%目标的季度数 | 期末现金 | 期末储备 | 累计基本篮子缺口 |
|---|---:|---:|---:|---:|
| 不干预 | 4 | 160.00 | 60.00 | 17.44 |
| 限价5 | 3 | 160.00 | 60.00 | 24.00 |
| 分两期释放储备 | 6 | 358.06 | 20.00 | 1.44 |
| 储备衔接恢复期补贴 | 6 | 258.06 | 20.00 | 1.00 |

两条储备路径均达到本剧本目标。增加恢复期补贴进一步减少基本篮子缺口，但期末现金少100。目标达成不构成某政策在所有环境下最优的证明；低收入组保障、生产者收益与储备留存仍需分别讨论。

# 复盘与学习评价

学习反馈独立于经营目标。下面每项按0、1、2级记录，属于教师自定的课堂量表，不是 Pearson 官方分数，也不转换为考试等级。AO名称与能力方向依据[官方考核说明](https://qualifications.pearson.com/en/news-policy/subject-updates/economics/ial-economics-assessment-support.html)。

| 能力 | 0级 | 1级 | 2级 |
|---|---|---|---|
| AO1 知识 | 概念错误或缺失 | 概念大体正确 | 准确区分均衡、短缺、限价和弹性 |
| AO2 应用 | 没有本局证据 | 引用数据但联系薄弱 | 用具体数值或图表支持判断 |
| AO3 分析 | 仅陈述结果 | 解释部分环节 | 给出完整且方向正确的因果链 |
| AO4 评价 | 无条件断言 | 提及条件但未权衡 | 比较方案并结合时间、约束和群体作判断 |

学生报告保留四个短段落：我的措施；发生的变化及证据；原因；在什么条件下我会改变决定。末尾评价任务为：Evaluate whether a maximum price was the most effective response to the food shortage in your country.

数量练习使用基期与歉收无干预两组数据，以基期为百分比基准：PED = ((70−100)/100) ÷ ((6.875−5)/5) = −0.80。说明这是指定区间和基准下的计算；不能把发生供给移动的两个均衡点拿来直接估算同一条供给曲线的PES，也不能用被配给后的成交量冒充该价格下的需求量。

迁移任务：某城市人口流入，短期出租住房供给缺乏弹性。政府拟将最高租金设在新均衡租金以下，并补贴新建出租住房。评价两项措施能否改善低收入家庭获得住房的情况。

迁移判据：识别需求右移；区分租金与实际住房获得；解释限价与配给；讨论建设时滞、供给弹性和政策条件。保留学生独立回答，再进行课堂讨论。

# 数值验证与原型验收

参考计算程序枚举了2592种季节、政策、期初现金和库存组合，其中1122种可执行组合通过了分配、现金、库存、交易付款、数量边界及剩余账目的核对。另有11项行为检查，覆盖基期均衡、不生效限价、短缺、补贴产能约束、储备影响、恢复期补贴、私人产出替代、预算不足、库存不足、复现和基期剩余，均通过。

这些结果验证的是所列规则的计算一致性。原型仍须检查交互与图表是否使用同一结算记录，课堂试玩则检查学生是否真正理解。

| 交付阶段 | 可检查的完成条件 |
|---|---|
| 经济模型接入 | 重现示例数值；无效政策不改动状态；历史记录保存未舍入结果 |
| 可玩界面 | 完成六回合，能查看政策、结果、账目和两组居民数据 |
| 回放 | 复制决策前状态及相同外生路径；支线比较不覆盖原始记录 |
| 图表检查 | 数量和价格轴正确；曲线、均衡、限价与实际交易点相符 |
| 小范围试教 | 观察独立完成情况，收集本局因果解释、条件判断及陌生情境迁移答案 |

第一版随后进入模型与界面实现。住房、污染等 Unit 1 剧本在首次试玩后扩展；宏观政策、企业竞争和全球经济分别保留在 Unit 2、Unit 3 和 Unit 4。
