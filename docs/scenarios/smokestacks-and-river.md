# 烟囱与河流：Edexcel IAL 生产负外部性剧本

《繁荣之路》第二个课堂剧本，版本日期：2026年10月20日。适用范围为 Pearson Edexcel International A Level Economics 的 Unit 1。玩家担任河港镇经济部长，在四个季度中选择单位污染税或排放总量上限，权衡纸张供应、河流损害与政策执行成本。

这是供教师审阅和后续界面实现的完整规则稿，不是已经上线的可玩关卡。所有参数均为教学假设，不是污染监测结果或现实政策建议。本关只生产一种商品“纸卷”，污染来自其生产过程；烟囱和河流是场景表现，不额外模拟空气污染市场。

## 学习目标与课程对应

学生完成本关后，应能区分私人成本与社会成本，解释自由市场为什么可能生产过多，比较税收与数量限制，并用本局证据作出有条件的判断。

| IAL 考纲位置 | 本关练习 | 可观察的学习证据 |
|---|---|---|
| 1.3.1 模型、机会成本与价值判断 | 区分参数事实、模型假设和镇议会目标 | 指出一个改变后可能影响结论的假设 |
| 1.3.4 均衡与间接税 | 分清消费者支付价格、生产者税后所得与税收 | 用数值解释税负分配 |
| 1.3.5 生产负外部性 | MPC、MEC、MSC、MSB，市场产量与社会最优产量 | 标注福利损失并解释其来源 |
| 1.3.6 政府干预与政府失灵 | 比较特定税与直接管制，考虑行政成本和信息 | 在相同环境下比较政策，而非只比较两个季度 |

以上仅涉及条目的相关部分。本版的排放上限属于直接管制，没有许可证交易，不冒称已覆盖可交易污染许可证。课程依据为 [Pearson IAL Economics Specification，Issue 2，印刷页18–21](https://qualifications.pearson.com/content/dam/pdf/International%20Advanced%20Level/Economics/2018/Specification-and-Sample-Assessment/International-A-Level-Economics-spec.pdf)，链接已于2026年10月20日核验。

## 玩家任务与课堂流程

开局公开三个经营目标，四季结束时分别检查：

- 累计纸卷供应至少130单位。
- 累计货币化外部损害不超过3000 credits。
- 每次执行政策前能支付行政成本，且国库始终非负。

目标包含固定的第一季，累计量从第一季开始记录。130和3000是镇议会制定的游戏阈值，不能替代完整社会福利判断；达到目标也不等于政策最优。输出量、排放量、外部损害和国库分别展示，不合成任意“满意度”分数。

建议课堂安排为基期引导3分钟、三次政策选择约12分钟、比较回放和报告8–10分钟。每季依次执行“读简报—查看证据—预测—选政策—执行—解释”。预测错误不会扣除资源或阻止继续。

第二、四季各保留一句预测及理由。第三季先提问：产量与排放没有改变时，河流损害为什么可能上升？最后学生选择一个已完成季度，复制当季条件和期初现金，尝试另一个政策；回放单独记录，不覆盖原局。

## 四回合剧本

| 季度 | 简报与公开参数 | 玩家动作与学习重点 |
|---|---|---|
| 1 烟囱升起 | 纸厂投产；需求参数 a=100，单位外部损害 m=20 | 固定无政策。查看市场出清40单位，但社会最优产量为30；价格机制尚未计入第三方损失 |
| 2 河岸请愿 | 环境报告公布；a=100、m=20，与第一季相同 | 开放全部政策。预测消费者价格和排放方向；比较税与数量限制如何分配收益 |
| 3 枯水期 | 河流稀释能力下降；a=100，m=40 | 外部损害系数翻倍，私人需求和生产成本不变；重新判断上季措施 |
| 4 新订单抵达 | 水量恢复，外地采购订单增加；a=120，m=20 | 需求右移且损害系数恢复。预测是否应保留上季税率或上限；解释退出或调整的理由 |

天气、订单和损害系数变化由剧本预设，所有政策路径使用同一组条件。第三季损害上升不是玩家上一季未治理造成的；本版不模拟污染存量累积、延迟健康损害或自然净化过程。

政策每季到期，下一季默认无政策。提供“沿用上季选项”按钮，但必须重新提交并承担当季行政成本。第一季仅允许无政策，不提前征税或设置上限。

## 参数与关键假设

| 项目 | 规则 |
|---|---|
| 商品与计量 | 纸卷为抽象产量单位；价格、成本、损害与现金均用 credits |
| 期初国库 B | 100 credits |
| 排放 E | 每生产1单位纸卷排放1单位污染，E=Q；没有减排设备选项 |
| 消费与生产 | 当季产量全部当季售出，无私人或公共库存 |
| 私人生产成本 | MPC(Q)=20+Q；无固定成本，无退出、投资或跨季生产决策 |
| 外部损害 | MEC(Q)=m；当季总外部损害 ED=mQ |
| 消费外部性 | 不存在，所以 MSB=MPB |
| 行政资源成本 F | 无政策0；征税20；设置上限30，每季支付一次 |
| 实施条件 | 完全遵守，产量与排放可精确观测；不存在逃税、黑市或执法延迟 |
| 分配约定 | 数量限制优先保留成本最低的生产单位；限额免费配置给现有生产者，无拍卖或交易 |

MEC是每多生产一单位给第三方带来的损害。它在一个季度内为常数，在季度之间按剧本改变。ED是损害估值，不是居民收到的赔偿，也不是国库现金支出；税收没有自动赔付居民或清洁河流的效果。

直接管制采用全行业排放总量上限。由于本版E=Q，它等价于产量上限。真实企业可能通过减排技术降低单位排放，这会打破这一等价关系。上限下的成本有效分配是强假设；现实中逐厂配额未必做到。

## 政策桌

每个决策季度只能选择一项措施，不能叠加税与上限。这样可以清楚比较两种工具，不引入组合政策引擎。

| 规则ID | 界面名称 | 数值 | 当季行政成本 |
|---|---|---:|---:|
| none | 暂不干预 | 税率0，无上限 | 0 |
| tax20 | 单位污染税20 | 每单位实际排放征收20 | 20 |
| tax40 | 单位污染税40 | 每单位实际排放征收40 | 20 |
| cap20 | 排放总量上限20 | E≤20，即Q≤20 | 30 |
| cap30 | 排放总量上限30 | E≤30，即Q≤30 | 30 |
| cap40 | 排放总量上限40 | E≤40，即Q≤40 | 30 |

行政成本从期初现金支付，不能借用尚未收到的当季税款。若B<F，政策不执行，历史和现金均保持不变。无政策始终可选。上限不产生税收；即使不约束市场产量，仍支付检查和管理成本。

提交前公开参数、政策条款与预算可行性，不直接显示求解后的结果；提交后可展开完整计算。按钮不会偷偷调整税率或限额。全部规则与公式始终可查，预测依赖学生推理而非隐藏信息。

## 确定性市场结算

令Q为实际产销量，p为消费者单价，t为单位税，C为可选上限，a和m为本季公开参数。实际涉及的产量范围为0≤Q≤50，需求边际愿付在此范围始终非负。

```text
MPB(Q) = MSB(Q) = a − Q
MPC(Q) = 20 + Q
MEC(Q) = m
MSC(Q) = MPC(Q) + MEC(Q) = 20 + Q + m
Qmarket = (a − 20) / 2
Qsocial = (a − 20 − m) / 2
```

上述Qsocial是**未计固定行政成本的配置效率基准**，解MSB=MSC。本版全部参数均使其为正。比较可执行政策时，还须扣除各自行政成本，不能单凭达到Qsocial便宣称净福利最大。

```text
无政策：Q = Qmarket，t = 0，F = 0
单位税：Q = (a − 20 − t) / 2，F = 20
数量限制：Q = min(Qmarket, C)，t = 0，F = 30
p = a − Q
生产者税后单位所得 pn = p − t
E = Q
```

税收使生产者面对的价格与消费者支付价格之间出现税额差。在供需图上可绘制MPC+t；真实MPC、MEC和MSC不因征税而自动下降。税额t=m时，MPC+t与MSC重合，产量达到Qsocial；这是本模型完整信息与执行假设下的结论。

数量限制约束时，价格升至需求愿付p=a−C，市场依然出清。私人技术成本曲线不移动，供给在C处停止扩张；p可能高于边际生产成本，差额形成生产者限额稀缺收益。这里没有面包剧本中的限价或比例配给。

结算顺序固定为：

1. 读取季度、a、m、期初现金和累计记录。
2. 检查选项是否允许；第一季强制none；检查B≥F。
3. 求Q、p、pn、E和Qsocial。
4. 计算成本、消费者与生产者剩余、税款、外部损害、福利和期末现金。
5. 检查数量、预算与会计恒等式；一次性保存记录，再生成图表和角色发言。
6. 累加产量和损害；仅在第四季后检查经营目标。下一季政策到期。

内部保留完整精度，展示时保留两位小数。下列示例恰好得到整数，不代表实现可提前取整。

## 剩余、财政与福利

```text
总消费收益 TB = aQ − Q²/2
私人总成本 PC = 20Q + Q²/2
消费者剩余 CS = TB − pQ = Q²/2
生产者剩余 PS = (p − t)Q − PC
政府税收 T = tQ
外部损害 ED = mQ
期末现金 Bnext = B + T − F
净社会福利 W = CS + PS + T − ED − F
              = TB − PC − ED − F
              = (a − 20 − m)Q − Q² − F
配置损失 L = Wgross(Qsocial) − Wgross(Q)
           = (Q − Qsocial)²
其中 Wgross(Q) = W + F
```

税款已经从生产者所得扣除，所以计算福利时加回政府税收；不能又将税款当作社会资源成本扣一次。F则代表真实行政资源的机会成本，除影响现金，也从福利扣除。初始100 credits只是资金余额，不额外加入福利。

相同产量下，税与限额的外部损害和消费者剩余相同，但税款归政府，免费限额的稀缺收益归生产者。没有固定成本时PS可视为本模型行业净经营收益，不应外推为现实会计利润。

界面同时列出配置损失L与行政资源成本F。总计相对于无行政成本基准的差额为L+F，不能把行政成本也涂成供需图中的三角形。福利指标仅代表上述货币化、等权加总的模型，不涵盖所有公平或生态价值。

限额稀缺收益公式表示相对于实际产量处边际成本的价格差形成的矩形部分；总PS还包括正常向上倾斜供给曲线下的剩余，不能把两者混为一谈。

## 学习报告与教师评价

结算完成后保留四段短报告：

1. **概念与判断：**为什么第一季市场出清仍存在市场失灵？准确区分MPC与MSC。
2. **本局证据：**选择一个季度列出Q、p、ED和W，并说明比较对象为何使用相同环境。
3. **因果解释：**说明税或上限如何改变产量、价格、外部损害和不同主体所得。

## 模型边界与验证验收

本版明确知道m、精确监测且完全执行，所以t=m容易找到。现实外部损害难以估计，不同居民承受损害不同，跨地区污染、长期技术投资、企业异质性、税收用途与执法都可能改变政策比较。暂不引入这些机制，课堂评价必须能够指出至少一个相关边界。

行政成本20与30刻意保留可见的工具差异，不能据此推断现实税制总比管制便宜。把两者行政成本设为相同、仍达到相同产量时，模型净福利相同；若税收行政成本更高，净福利排名可能反转。国库不足与总福利高低是不同问题。

当前验证文件为 `tests/pollution-scenario.test.ts`，它是文稿数值核对用的独立参考计算，不是已接入游戏的第二套运行引擎。检查直接读取本稿18行单季表、两条路径8行逐季表及3行汇总表，避免只验证一份与文稿无关的抄录数据；另枚举三次决策的216条路径，核对预算、数量边界与福利恒等式。
