# 繁荣之路 · 首轮学生试玩包

试玩版本：2026.10.21。Pearson Edexcel IAL Economics Unit 1 的供求、最高价格、生产补贴与资源稀缺构成世界规则。玩家通过经营城镇感受政策后果；游戏不设置预测题、知识测验或学习报告关卡。数值来自简化模型，不代表现实预测。

## 教师先做什么

1. 先邀请3–5名学生，每人使用独立浏览器或设备；预留15–20分钟自主试玩。
2. 在学校实际网络与学生设备上打开 [游戏链接](https://prosperity-road-ial.bingkunq.chatgpt.site/)。网站公开访问，无需学生账号。发布环境的测试不能替代学校网络实测。
3. 直接让学生开始玩，不要求先阅读说明、观看演示或回答经济题。卡住超过30秒再给予最小提示，并记录提示内容。
4. 想收集反馈时，可给学生 P01、P02 等代号，说明自愿下载的反馈文件交到哪里。不要填写真实姓名和联系方式，也不要把交文件当成通关条件。
5. 共享设备换人前，先保存需要的任期记录，再从“菜单”点击“新任期”。确认后会清除当前游戏进度与反馈草稿；各设备的进度不会同步。

游戏未接入玩家行为统计，也不会自动向教师发送成绩或反馈。首轮观察主要回答：学生能否自己玩起来，能否看懂决定带来的变化，是否想尝试另一种做法。

## 20分钟试玩安排

| 时间 | 留给玩家的空间 | 教师观察什么 |
|---|---|---|
| 0–2分钟 | 自己打开游戏，开始任期 | 首次有效操作耗时；是否知道下一步点哪里 |
| 2–8分钟 | 选择政策，执行，回应新的局势 | 是否看到街头反应；改变选择时是否有自己的理由 |
| 8–15分钟 | 继续任期，自由走访、对话或试算 | 哪些内容吸引主动点击；是否想尝试其他方案 |
| 15–20分钟 | 查看战报，再玩一局，或自愿留下反馈 | 是否理解成败；想再次改变什么；哪里打断了体验 |

不要为了收集完成率而替学生操作，也不要中途插入知识测验。学生卡住时，先记录发生了什么，再提供必要帮助。

## 首轮后如何决定改什么

- 首先修复阻断问题：打不开、无法执行、无法进入下一季、结果丢失。
- 其次修复多人重复卡住的操作，以及玩家做了决定却看不出任何变化的地方。
- 留意学生是在主动权衡，还是因为信息不足而随意点选；先改善局势与后果的呈现。
- 暂定的下一轮条件：至少80%学生能在20分钟内自主完成六季，核心流程每人最多需要一次提示，未出现阻断问题。反馈文件不是完成条件。
- 想提高吸引力时，优先改进人物回应、可观察的城镇变化与有代价的选择，不急于添加考试题、账号、排行榜或更多数值。
- 首轮样本很小，只用于发现问题，不能据此声称具有普遍教学效果。

## 已知边界

- 游戏进度与反馈草稿保存在当前浏览器；更换设备、清理浏览器数据、无痕窗口关闭都可能使进度无法继续。
- 任期战报自动生成，可下载为“面包危机-任期记录.md”；没有需要填写的学习报告。
- 自愿反馈可中途导出，包含当前阶段和已经结算的政策数据；未完成时不冒充完整任期成绩。
- 林岚是情境选项对话，尚不支持自由输入或语音聊天。
- 当前只有《面包危机》接入可玩界面。动画展示流向，不表示成交数量。
- 视频可提前下载用于教室播放。学校网络或特定手机浏览器的兼容性，需要老师用实际设备再确认。
