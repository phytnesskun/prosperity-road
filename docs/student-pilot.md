# 繁荣之路 · 首轮学生试玩包

试玩版本：2026.10.21。适用内容：Pearson Edexcel IAL Economics Unit 1 的供求、最高价格、生产补贴、资源稀缺与政策评价。本游戏是课堂简化模型，不代表现实预测或官方考试评分。

## 教师先做什么

1. 先邀请3–5名学生，每人使用独立浏览器或设备；预留20分钟试玩和5分钟讨论。
2. 在学校实际网络与学生设备上打开 [游戏链接](https://prosperity-road-ial.bingkunq.chatgpt.site/)。网站已设为公开访问，无需学生账号。发布环境的测试不能替代学校网络实测。
3. 告诉学生用 P01、P02 等代号，不填写真实姓名和联系方式；说明把下载的反馈文件交到哪个班级平台或文件夹。
4. 首轮先让学生阅读网站“菜单”内的“试玩与反馈”，自行操作。卡住超过30秒再给予最小提示，并记录提示内容。可以在试完后播放演示，避免把视频代替独立上手测试。
5. 共享设备换人前，先收取文件，再从“菜单”点击“新任期”。这会清除当前游戏进度与反馈草稿；各设备的进度不会同步。

游戏未接入玩家行为统计，也不会自动向教师发送成绩或反馈。首轮证据来自现场观察与学生主动交回的文件。

## 20分钟活动安排

| 时间 | 学生任务 | 教师观察什么 |
|---|---|---|
| 0–2分钟 | 打开游戏，观察正常市场，说出任务目标 | 首次有效操作耗时；是否理解实际购粮与价格不同 |
| 2–6分钟 | 自选第2季方案，点下一步，预测，再执行 | 是否能说出当前任务、选中方案和下一步；是否能返回修改 |
| 6–9分钟 | 免费试算一次，只改一个政策；问林岚 | 能否区分正式记录与试算，是否能找到比较结果 |
| 9–14分钟 | 完成剩余季度 | 是否根据原料、现金、库存变化调整判断 |
| 14–18分钟 | 用具体数字写学习复盘 | 是否有措施、证据、因果、适用条件 |
| 18–20分钟 | 填写并下载试玩反馈；交给老师 | 能否找到文件，是否知道下载不等于已提交 |

如果学生中途卡住，保留当前局面，直接下载反馈。不要为了收集“完成率”而替学生操作。

## 三道学习检验题

先让学生独立回答，再展开参考要点。这是课堂诊断，不是Pearson官方题目或评分标准。

1. 第2季将最高价格设为5，为什么低收入组可能买得更少？用同一季度的两个结果支持解释。
2. 同样每单位补贴1，为什么在第2季和第4季的生产效果可能不同？
3. 出售公共储备后国库现金增加，是否说明应该一直开仓？至少指出一个未来代价。

<details>
<summary>教师参考要点</summary>

- 第1题：有效限价降低生产者得到的价格，私人供给减少；需求增加而可售量受限，发生配给。第2季只限价5时低收入实际购粮24，同条件无干预25。不能拿上季40当“限价的单独效果”。
- 第2题：补贴提高生产激励，但不提高原料上限。歉收期约束可能已达到，恢复期才可能有增产空间。应结合各季相同资源下的对照，而不是只看跨季差异。
- 第3题：现金增加伴随储备减少，还存在配送成本、未来应急能力与机会成本；同时观察居民获得，不把现金变化当成总福利变化。

## 首轮后如何决定改什么

- 首先修复阻断问题：打不开、无法继续、结果丢失、下载失败。
- 其次修复多人重复卡住的操作，再修复常见经济误解。
- 建议进入下一轮的暂定标准：至少80%学生在20分钟内完成六季并交回反馈，核心流程每人最多需要一次教师提示，未出现阻断问题。
- 若操作已顺利但解释仍弱，修改对照呈现和追问，不急于增加新剧本、账号、排行榜或更多数值。
- 首轮样本很小，只用于发现问题；不能据此声称提升了考试成绩或具有普遍教学效果。

## 已知边界

- 游戏、反馈与学习报告保存在当前浏览器；更换设备、清理浏览器数据、无痕窗口关闭都可能使进度无法继续。

- 林岚是情境选项对话，尚不支持自由输入或语音聊天。
- 当前只有《面包危机》接入可玩界面。动画展示流向，不表示成交数量。
- 视频可提前下载用于教室播放。学校网络或特定手机浏览器的兼容性，需要老师用实际设备再确认。
