## 制作与核对

- 讲稿改为口语短句，靠标点保留自然停顿；晓晓语速 −4%。按新旁白时长重新录屏，没有加速音轨去迁就旧视频。
- 先运行 `scripts/render-demo.py prepare` 生成神经旁白，再运行 `scripts/record-demo.mjs` 实际操作录屏，最后运行 `scripts/render-demo.py render` 混入配乐。网络与依赖说明见本目录 README。
- 使用独立浏览器，从正常入口推进，不注入预设存档。限价方案选好后直接执行；微调只展示开合，不改变政策。
- 第一季正常市场价格 5、低收入购粮 40；第二季限价 5 后购粮 24。免费试算取消限价后，同季购粮 25、价格 6.88，比较条件相同。
- 片中实际推进前两季，随后展示对话、试算、城镇和可选反馈；没有提供六季最优路线。结尾口播说明六季后自动生成任期战报。
- 配乐使用 `public/audio/town-theme.mp3`，前后淡入淡出，旁白出现时降低乐声、停顿时恢复。录屏不混入第二份游戏音轨。
- 旁白是标准合成声，不是真人录音或声音克隆；林岚仍采用选项式互动，不暗示自由语音聊天。
- 成片为 1440×900、25 fps、H.264 / 双声道 AAC，116.96 秒，约 4.85 MiB。时间轴、字幕、独立声轨和最终混音的技术核验见 `verification.md`。
