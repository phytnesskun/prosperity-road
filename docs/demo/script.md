## 制作与核对

- 先运行 `scripts/render-demo.py prepare` 生成语音，再运行 `scripts/record-demo.mjs` 真实操作录屏，最后运行 `scripts/render-demo.py render` 合成。详见本目录 README。
- 使用独立浏览器环境，从正常入口推进；不注入预设存档。限价方案选好后直接执行，可选微调只展示开合，不改变政策。
- 录制脚本确认执行前没有预测控件。林岚直接说明居民处境，没有答题或回答正确后解锁的环节。
- 第一季正常市场价格 5、低收入购粮 40；第二季限价 5 后购粮 24。免费试算取消限价后，同季购粮 25、价格 6.88，比较基于相同天气、成本与期初资源。
- 片中实际推进前两季，随后展示对话、试算、城镇和可选反馈；没有提供六季最优路线。结尾口播说明六季后自动生成任期战报，不要求填写学习报告。
- 片中未展开演示视频播放器，避免视频内再播放自身。旁白是系统合成语音；林岚是选项式互动，不暗示自由语音聊天。
- 讲稿与字幕使用实际录制时间轴。字幕条单独留在网页画面外，不遮挡主操作区。
- 成片为 1440×900、25 fps、H.264 / AAC，109.96 秒，约 4.19 MiB。全片解码通过；已检查七个成片画面、字幕和实际浏览器播放。完整验收见 `verification.md`。
